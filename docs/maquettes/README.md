# Maquettes

Les maquettes des écrans touchés par les user stories du sprint, faites au
sprint planning avant d'écrire le code. Chaque maquette montre l'écran,
l'enchaînement du parcours, et les états vide, erreur et chargement.

Une image par écran, exportée depuis l'outil de votre choix (Excalidraw,
Penpot). Nommez les fichiers par sprint et par écran, par exemple
`sprint-1-liste-des-commandes.png`.
